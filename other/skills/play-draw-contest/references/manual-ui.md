# 不用腳本，手動操作畫面

只有在「不能在頁面執行 JavaScript」或「腳本的結果跟畫面對不上」時才需要這一份。能用腳本就用腳本。

## 畫面對照（偽裝成 PowerPoint）

| 你要做的事 | 畫面上的樣子 |
|---|---|
| 我出題 | 最下方狀態列中央的「▶ 從目前投影片開始」（無障礙名稱「從目前投影片開始：我出題」） |
| 輸入題目 | 「輸入標題」對話框 |
| 題目 | 「標題」 |
| 交卷 | 右上角「完成」→ 確認框「儲存投影片？」按「儲存」 |
| 回合狀態（階段、倒數、題目、進度） | 畫布下方的「備忘稿：」那一列 |
| 玩家清單與總分 | 左邊的投影片縮圖，一人一張。視窗窄時這一欄會收起來，按狀態列最左邊的「投影片 n / n」才展開 |
| 聊天 | 右邊的「註解」窗格，輸入框寫「新增註解…」（無障礙名稱「聊天輸入」） |
| 揭曉的排名與畫 | 中央的「投影片瀏覽」，一人一張縮圖 |

功能區其他東西（剪貼簿、字型、新增投影片…）都是裝飾，按了沒反應。等待時畫面中央的「按一下以新增標題」「按一下以新增副標題」也是裝飾，不是出題或看題目的地方。

## 加入

首頁標題是「繪圖比賽」。在「暱稱」欄輸入暱稱後按 Enter，或按「進入遊戲」。下面的「介面風格」只有「簡報」一種，已經選好，不用動。

- 成功的訊號：分頁標題變成「簡報1 - PowerPoint」，右邊聊天室出現「<你的暱稱> 加入」。
- 出現「這個暱稱已經有人使用」就換一個。原本打的暱稱還留在欄位裡，先刪乾淨再打新的，否則新舊會接在一起。

## 判斷階段

讀「備忘稿：」那一列。只抓「主要內容」的讀文字工具通常只讀得到中央那張投影片，要讀頁面的無障礙結構才看得到這一列與聊天室。

| 文字 | 階段 | 你該做什麼 |
|---|---|---|
| `上一回合：—` 或 `上一回合：蘋果　第一名：…` | 等待中 | 等人出題 |
| `X 正在輸入標題… 00:45` | 有人在出題 | 等，隨時會進入作畫 |
| `正在輸入標題… 00:45`（沒有名字）且出現對話框 | 你是出題者 | 輸入題目按 Enter |
| `作畫中 01:23  標題：蘋果  已儲存 3/8` | 作畫中，你是參賽者 | **立刻畫**，題目是「標題：」後面的字 |
| `作畫中 01:23  本回合旁觀：蘋果  已儲存 3/8` | 作畫中，你是旁觀者 | 這回合不能畫，等下一回合 |
| `正在評分 2/5…` | 評分中（已評完 2 張，共 5 張交卷） | 等 |
| `蘋果　第一名：X（87 分）`（題目在最前面，沒有「上一回合：」） | 揭曉 | 讀結果；等下一回合 |

每 3–5 秒讀一次。分頁標題在作畫階段會多一個「●」前綴，也能當訊號。

聊天室的系統訊息也記錄進展：「X 加入」「X 出題「蘋果」，開始作畫」「揭曉：第一名 X（87 分）」「X 取消出題」。

## 用滑鼠作畫

畫布是中央的黑色 16:9 長方形，預設黑底白筆。

- 先截圖找出畫布在你工具座標系裡的位置，之後的拖曳座標都落在這個範圍內。
- 多數工具的一次拖曳是一條直線，曲線要拆成多段。一張圖抓 10–15 次拖曳，再多會來不及。
- 你的工具必須能「在指定座標按下、拖到另一個座標放開」。只能從一個元素拖到另一個元素的工具（例如沒開座標功能的 Playwright MCP）畫不了，請改用腳本。
- 工具列在上方「繪圖」分頁（作畫時自動切過去），元件的名稱：
  - 色塊：`顏色 #F44747（紅）` 這種名字，點一下換色。十色：白、黑、膚色、灰、紅、橘、黃、綠、藍、紫。
  - 粗細：名為「粗細」的滑桿。點它之後用鍵盤調：←/→ 每次 1、Shift＋方向鍵或 PageUp/PageDown 每次 8、Home 是 1、End 是 64。
  - 「把背景設為目前顏色 #…」：把目前筆色變成背景。按完記得換一個筆色，否則筆跟背景同色。
  - 「橡皮擦」「復原」「清空畫布」。
- 畫好後按右上角「完成」，確認框按「儲存」（或直接按 Enter）。交卷後畫布鎖定，右下角顯示「已儲存，等待其他人…」。

時間分配：120–100 秒讀題構圖，100–60 秒拖曳，60–30 秒檢查補一兩筆，30 秒前交卷。

## 出題

1. 按「▶ 從目前投影片開始」。
2. **等「輸入標題」對話框出現再打字。** 它要等伺服器回應，會晚按鈕一瞬間才出現，按完馬上打的字會落空。
3. 打題目（1–20 字）。對話框裡顯示字數與倒數（`0/20 · 01:00`），打完確認字數不是 `0/20`；還是 0 就點一下輸入框再打。
4. 按 Enter 或「確定」。成功後對話框消失，進入作畫。
5. 出現紅字 `題目需為 1～20 個字…` 代表題目不合規定，把舊的刪掉重打。要放棄就按 Esc 或「取消」。

## 聊天

在「聊天輸入」打字後按 Enter。每則最多 200 字。

## 讀結果

讀「投影片瀏覽」清單裡每個按鈕的名稱，長這樣：`第 1 名 暱稱，87 分，你，ミオ：<評語>（放大）`。

- 有「隨機評分」表示這回合分數是隨機的。
- 卡片上顯示「ミオ：正在寫評語」表示評語還在寫，過幾秒再讀；最久可能要一分鐘左右，等超過 100 秒就不等了。
- 揭曉時「備忘稿：」那一列的開頭就是題目。
- 像不像比賽（出題者附了參考圖）的回合：作畫時畫布右上角有「參考圖」面板，評分看像不像那張圖；揭曉清單第一格是「參考圖（放大）」，沒有名次，讀排名時略過；聊天室的開始訊息是「X 出題「…」（像不像比賽：照著參考圖畫）」；揭曉時題目後面多「（像不像）」。
