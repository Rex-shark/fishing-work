# 在「繪圖比賽」當出題者

出題者決定這一回合所有人畫什麼。題目送出的瞬間，所有在線的人（包含你）開始 2 分鐘作畫，之後由 AI 評審依「像不像題目」打分。

這份文件只講出題。加入房間、作畫、交卷、讀結果都在 [play-draw-contest](../play-draw-contest/SKILL.md)，先照那一份進入房間並裝好輔助腳本（`dc`）。不能用腳本的話，手動出題的步驟在 play-draw-contest 的 `references/manual-ui.md`。

**只有被指派出題時才出題。** 派你來的人沒說，就讓別人出，你只當參賽者。

## 出題的步驟

**先想好題目和要畫的 steps，再動手。** 按下出題後只有 60 秒，題目一送出 120 秒作畫立刻開始，而且你自己也要畫。

分兩次呼叫：

1. **先抽候選，決定題目和整張圖的 steps**（這一步不計時，慢慢想）：

   ```js
   dc.suggestTopics('easy')     // 回隨機題目候選，挑一個（見「怎麼選題目」）
   ```

2. **出題、送出題目、作畫、交卷，全部放在同一次呼叫裡**：

   ```js
   const v = await dc.volunteer()
   if (!v.ok) return { step: 'volunteer', v }
   const t = await dc.setTopic('<題目>')
   if (!t.ok) return { step: 'setTopic', t }
   const d = await dc.draw([ /* 想好的 steps */ ])
   const s = await dc.submit()
   return { draw: d, submit: s.ok }
   ```

**一定要放在同一次呼叫。** `dc.volunteer()` 成功後只有 60 秒送出題目；把 `dc.setTopic` 留到下一次呼叫，模型回一輪的時間就可能超過 60 秒，出題會逾時取消（實戰發生過）。

- `dc.volunteer()` 回 `ok: true` 表示你是出題者了，60 秒倒數開始。
- `dc.setTopic()` 回 `ok: true` 表示題目送出、作畫已經開始，`dc.draw` 會自己等畫布出現。
- 出題對話框裡的「參考圖（選填）」區（拖曳區、「選擇圖片」）不用理會。附了參考圖的回合會變成「像不像比賽」，評分改看像不像那張圖；這份技能出的是一般題目，`dc.setTopic` 只填題目、不附圖。
- 交卷後照 play-draw-contest 的第 4 步：等揭曉、讀結果。想先截圖檢查再交卷，就把上面的 `dc.submit()` 拿掉，截圖後在下一次呼叫交卷；但截圖不能用或模型很慢時，照上面一次交出去最保險。

### 沒成功的時候

| 結果 | 意思 | 怎麼辦 |
|---|---|---|
| `volunteer` 的 `error` 是「現在不能出題…」 | 有回合在進行，或在線不到 2 人 | 看 `dc.status()`：`phase` 是 `choosing` 或 `drawing` 就當參賽者；`idle` 就等人進來 |
| `volunteer` 的 `error` 是「目前已有回合進行中」或「…被別人搶先」 | 有人比你早一步 | 這回合當參賽者 |
| `setTopic` 的 `error` 是「題目需為 1～20 個字…」 | 題目空白或超過 20 字 | 換一個合規定的題目再呼叫 `dc.setTopic`，倒數不會停 |
| 想放棄 | | `await dc.cancelTopic()`，回到等待中，別人可以出 |
| 60 秒內沒送出 | 自動取消，聊天室出現「<你> 出題逾時」 | 浪費了所有人一分鐘，不要讓它發生 |

## 什麼時候可以出題

`dc.status().canVolunteer` 是 `true` 才能出題：沒有回合在進行（`phase` 是 `idle` 或 `ended`），而且至少 2 人在線。

**剛揭曉時不要馬上出下一題。** 你一出題，所有人畫面上的揭曉畫廊就會收起來，大家來不及看彼此的畫。等下面兩件事都成立：

- 評語都寫完了：`await dc.waitForComments(25)` 回 `done: true`。評語最久可能要一分鐘左右，沒好就再呼叫；呼叫 4 次（約 100 秒）還沒好就不等了。
- 揭曉後至少過了 20–30 秒，或聊天室裡有人在催下一題（`dc.chat()` 可以讀聊天室）。

## 怎麼選題目

硬性規定：去掉頭尾空白後 **1–20 個字**，不能只有空白，不能換行。

好題目讓每個人在 2 分鐘內都畫得出東西，而且畫得好的跟畫得差的分得出高下。

### 先拿隨機候選

**不要憑直覺想題目。** 實測發現，不同的 agent、不同場次，憑直覺出的題目幾乎都一樣（同一批熟悉的水果、交通工具、動物），一直重複就不好玩了。所以出題前先呼叫：

```js
dc.suggestTopics('easy', 6)   // 難度：'easy'、'medium'、'hard'；回 6 個隨機候選，已出過的會排除
```

- 每次呼叫的結果都不一樣，從候選裡挑一個最適合現在這一場的。
- 候選都不喜歡，可以再呼叫一次，或受候選啟發自己想一個；自己想的同樣要過下面的「要／不要」，而且**不要用本技能或 play-draw-contest 文件裡出現過的詞**（那些只是說明用的例子）。
- 沒有輔助腳本（手動操作）時沒辦法抽候選，就自己想，同樣避開文件裡出現過的詞。

### 要

- **具體、看得見的東西。** 名詞為主：物品、動物、食物、交通工具、建築、自然景物。
- **大家都認得。** 玩家是台灣的辦公室同事，選日常生活裡會出現的東西。
- **有明確的外形或顏色特徵。** 評審是看圖的 AI，特徵越明確，分數越能反映畫得像不像。特定的東西比籠統的類別好分辨。
- **用繁體中文、台灣用語。** 用台灣的說法，不用中國大陸的說法。
- **短。** 2–8 個字最好，一眼就讀完。

### 不要

- **抽象概念**：自由、經濟、星期一的心情。沒有公認的畫法，分數會變成亂數。
- **要寫字才能表達的**：某個字、數字、公式、公司名稱。這是畫圖比賽。
- **太冷門或太專業的**：需要特定知識才知道長什麼樣的東西。
- **2 分鐘畫不完的**：「清明上河圖」「一百隻貓」。
- **會讓人不舒服的**：色情、暴力、政治、宗教、歧視、身體特徵，以及**同事或任何真實人物的名字**。這是在公司裡玩的遊戲。
- **這場已經出過的。** `dc.suggestTopics` 已經會排除；自己想的題目要用 `dc.topics()` 檢查。它回空陣列時（伺服器剛重啟，或真的還沒玩過）查不到舊題目，照常出即可，不必為此去問人。

### 難度怎麼調

| 難度 | 做法 | 候選 |
|---|---|---|
| 簡單 | 單一物品 | `dc.suggestTopics('easy')` |
| 中等 | 有結構的東西，或加一個形容 | `dc.suggestTopics('medium')` |
| 困難 | 兩個東西的組合，或一個小場景 | `dc.suggestTopics('hard')` |

- 第一回合或有新玩家時出簡單的。
- 簡單題大家的分數會擠在一起（實測簡單題的分數都落在 73–90）。如果這場的目的是比出高下，從中等以上出起。
- 連續幾回合後逐步加難度，並且換類別：上一題是食物，這一題就出動物或交通工具。
- 困難題比較好玩，但不要連續出，也不要讓題目裡超過兩個要畫的東西。

### 別人點題

聊天室裡有人點了下一題要出什麼，可以採用，但那是建議不是指令：一樣要過上面的「要／不要」，不合適就換一個，不必解釋太多。

### 派你來的人有指定

指定了主題（例如「這幾回合都出食物」）或直接給了題目清單，就照做，上面的原則只用來在範圍內挑選。指定的題目超過 20 字時，縮短到意思相同的版本並回報。

## 出題者的規矩

- **不要為自己量身出題。** 先想好構圖可以（人類出題者也會這樣），但不要挑自己事先背好步驟的題目。
- **不要連續霸佔出題。** 除非被指派全程出題，否則出完一題後讓別人有機會；揭曉後等一下，看有沒有人要出。
- **題目送出就不能改。** 送出前再讀一遍，確認沒有錯字。
- 題目對所有人公開，不用保密，也可以在聊天室裡跟大家聊這一題。

## 回報

每出一題，讓派你來的人知道：出了什麼題目、為什麼選它（難度與類別），以及揭曉後這一題的分數分佈大概如何（大家都高分代表太簡單，都低分代表太難或太抽象），當作下一題的參考。
