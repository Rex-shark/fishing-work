## 1. 偽裝語意

| 遊戲元素 | Meet 對照 |
|---|---|
| 出題（選題庫） | 控制列「分享音訊」按鈕（我畫你猜的「分享畫面」位置、同圖示風格改為喇叭）；對話框「分享音訊」（Epic 18）：頂部 segmented 三選一「歌手／台灣熱門／西洋熱門」（預設歌手；`role="radiogroup"`）。**歌手**：欄位「歌手」，placeholder「輸入歌手名稱（例如：孫燕姿）」，欄位下方勾選「只抽熱門歌」（預設勾；本機偏好 localStorage `fishing-work:song-guess:hot`）。**台灣熱門／西洋熱門**：一行 `--fg-on-panel-muted` 說明（對話框是白卡片，DESIGN §15 白底用面板 token；水手長 2026-10-16 修正）「從今天的 Apple Music 台灣熱門 100 首隨機抽 5 首」（西洋：「…美國熱門 100 首…」），沒有欄位。按鈕「取消／分享」；送出中按鈕文字「搜尋中…」（榜單模式「取得排行榜…」）、欄位 `readOnly` ＋ `aria-busy`，失敗後焦點留在原處 |
| 播放中的試聽 | 舞台主畫面 tile：左上標籤「<出題者> 正在分享音訊」；tile 中央是**音訊波形動畫**（5～7 根 `--accent` 直條依播放進度跳動，不讀真實音訊，純 CSS）＋ 下方 12px `--fg` 兩行（Epic 18）：第一行「{topic}{歌手模式且熱門時加「（熱門）」} · 第 2 / 5 首」（例「孫燕姿（熱門） · 第 2 / 5 首」、「台灣熱門 · 第 2 / 5 首」），第二行「歌手：{song.artist}」（歌手模式若與 topic 相同則省略）；**沒有專輯封面、沒有歌名** |
| 歌名字數提示 | 字幕列（roundStatus 插槽）：「歌名 ＿ ＿ ＿（3 字） · 00:21」倒數為試聽剩餘秒數 |
| 音量 | 控制列麥克風按鈕左側加一個 24px 喇叭圖示＋ hover／focus 時滑桿**浮在圖示上方**（不往旁邊展開，避免控制列位移）；本機偏好 localStorage |
| 猜題 | 右側「通話中的訊息」面板，同我畫你猜；輸入列提示「輸入歌名或聊天」，猜對後改「聊天（不可說出歌名）」；猜對 → `correct` 訊息「X 猜對了」綠字打勾（`--sem-type`），本人另見「你猜對了 +87」 |
| 每首揭曉（5 秒） | 舞台 tile 換成：左側 120px 專輯封面（`artworkUrl` 300px 版，圓角 8px）、右側歌名 20px `--fg`、歌手 14px `--fg`（DESIGN §15.1：tile 內承載資訊的文字一律 `--fg`，`--fg-muted` 在 tile 上只有 4.0:1；2026-10-12 定案；沒有封面時的佔位音符圖示例外，是圖形、在自己的 `--bg-editor` 方塊上，保留 `--fg-muted`）、下方猜對者列（暱稱＋分數膠囊，依順序）；沒人猜對顯示「沒有人猜對」；標籤改「第 2 / 5 首」；字幕列「下一首 00:04」 |
| 本局排名（ended） | 舞台 tile 換成表格：名次、暱稱、本局得分、猜對首數；前三名 `--accent`；標題「本局結果 · {lastTopic}」（「孫燕姿」／「台灣熱門」／「西洋熱門」）；停到有人分享音訊。idle 有上一局結果時同樣顯示（標籤「上一局」） |
| 參加者 tile | 同我畫你猜：頭像圓、暱稱、右下**總分**膠囊；出題者左上喇叭圖示＋ `--border-focus` 外框；本首已猜對右上舉手圖示 `--accent`；斷線 `opacity .5` |
| 說明 | 控制列「資訊」→ 兩步說明對話框（主題：怎麼玩、出題、猜歌、計分、聲音與耳機、切換偽裝），內容一份 |

## 2. 各階段對照

| phase | 舞台 | 字幕列 | 控制列「分享音訊」 |
|---|---|---|---|
| idle（無結果） | 「尚無人分享音訊」（舞台中央；左上不重複標籤） | 「按「分享音訊」出題（需 2 人以上）」 | 可按；人數不足時**灰化不可按**（`opacity .5` 的非按鈕元素）＋上方小字「等待其他玩家加入（n/2）」（驗收 2026-10-12 依實作修正） |
| idle（有上一局結果） | 上一局排名表 | 同上 | 可按 |
| choosing（自己是出題者） | 對話框「分享音訊」（三選一；見 §1） | 「正在出題 · 00:52」 | 作用中（`--accent`） |
| choosing（其他人） | 「<出題者> 正在準備分享音訊…」 | 「等待 <出題者> 出題 · 00:52」 | 不可按 |
| playing | 波形動畫＋題庫標題、本首歌手與第 n / 5 首 | 「歌名 ＿ ＿ ＿（3 字） · 00:21」；自己已猜對改「你猜對了 +87 · 00:21」 | 不可按 |
| reveal | 揭曉卡 | 「下一首 00:04」（第 5 首：「本局結束」） | 不可按 |
| ended | 本局排名表 | 「本局第一名：X（n 分）」；第一名 0 分時「本局結束：沒有人猜對」（與聊天系統訊息一致；Epic 18 順帶修） | 可按 |

## 3. 音訊行為

- `<audio>` 隱藏（`aria-hidden`），`preload="auto"`；playing 收到 `round:update` 即設 `src`，`loadedmetadata` 後 `currentTime = max(0, (serverNow − startedAt) / 1000)` 再 `play()`。
- 瀏覽器擋自動播放（`play()` 被拒）或試聽載入失敗時：舞台 tile 中央顯示同一顆按鈕「點一下開始播放」，點了再載入並 `play()`；加入遊戲的點擊通常已滿足互動條件，此為保險。
- reveal／ended／idle：`pause()` 並清 `src`。
- 音量滑桿 0～100，預設 **15**（Rex 2026-10-12：辦公室用預設要小；原 60），存 localStorage `fishing-work:song-guess:volume`。
- 試聽長度以 `durationMs` 為準：`<audio>` 的 `ended` 事件早於 server 計時器時只停播，畫面仍等 server 的 reveal。

## 4. 響應式與可及性

沿用 DESIGN §15.3（< 1024px 影片條移到下方；< 768px 面板改覆蓋層）。沒有工具列，所以沒有收合斷點。揭曉卡在 < 480px 時封面縮 80px、文字換行。所有狀態變化以獨立的 `role="status"` 元素朗讀（第 n 首開始、猜對、揭曉歌名；不含倒數）。人數不足的小字在 idle 與 ended 都顯示。
