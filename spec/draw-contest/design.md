## 2. 簡報殼層：各階段對照

| 階段 | 投影片區（中央） | 功能區 | 備忘稿列 | 左縮圖窗格（玩家） | 狀態列中段 |
|------|------|------|------|------|------|
| idle（無結果） | 空白標題投影片「按一下以新增標題」（裝飾） | 「常用」作用 | 「上一回合：—」 | 每人一張縮圖卡（暱稱、總分） | **「▶ 從目前投影片開始」＝我出題**（人數不足灰化＋「等待其他玩家加入（n/2）」） |
| idle／ended（有結果） | **投影片瀏覽**（§3） | 「常用」 | 「上一回合：蘋果　第一名：X（87 分）」；隨機評分時加「（隨機評分）」 | 同上 | 同上（ended 可直接出題） |
| choosing（我是出題者） | 空白投影片（畫廊不顯示；上一回合摘要只在備忘稿）＋ **「輸入標題」對話框**（題目輸入；Enter 送出、Esc 取消＝放棄出題） | 「常用」 | 「正在輸入標題… 00:45」 | 出題者卡外框 2px `--accent` | 灰化 |
| choosing（其他人） | 空白投影片 | 「常用」 | 「X 正在輸入標題… 00:45」（最後 10 秒同樣 `--sem-warning`） | 同上 | 灰化 |
| drawing（參賽者，未交卷） | **自己的畫布**（黑底 16:9，投影片框＋陰影） | **「繪圖」作用**：工具列（同我畫你猜）＋ 右端 **「完成」**主要按鈕（＝交卷，先開「儲存投影片？」確認框：「儲存後不能再修改」「儲存」「取消」） | 「作畫中 01:23  標題：蘋果  已儲存 3/8」；最後 10 秒 `--sem-warning` | 參賽者卡：作畫中無記號、**已交卷右上綠勾**（同猜對勾）；旁觀者卡 `opacity .5`＋「旁觀」；自己的卡底 `--bg-active` | 灰化 |
| drawing（已交卷） | 自己的畫布，鎖定（`pointer-events: none`，右下角小字「已儲存，等待其他人…」） | 「常用」（工具列消失） | 同上 | 同上 | 灰化 |
| drawing（旁觀者） | 空白投影片 | 「常用」 | 「作畫中 01:23  本回合旁觀：蘋果  已儲存 3/8」 | 同上 | 灰化 |
| judging | 自己的畫布鎖定（旁觀者空白） | 「常用」 | 「正在評分 n/m…」（**m＝已交卷數**，不是參賽人數，否則有人未交卷時永遠到不了 m/m；剛進 judging 時自動交卷在途會短暫顯示 1/1 再跳 1/4，可接受）；AI 退回隨機時加「（隨機評分）」 | 右上綠勾（分數小字 **v1 不做**：需每人評分欄位，不值得改契約） | 灰化 |
| ended | **投影片瀏覽**（§3） | 「常用」 | 「第一名：X（87 分）」 | 卡片顯示總分 | 「▶ 從目前投影片開始」可按 |

- 標題列：「簡報1 - PowerPoint」，作畫中前綴 `● `；右側連線狀態。`document.title` 同步。
- 右註解窗格：純文字聊天（卡片樣式同 §13.2），輸入框 placeholder「新增註解…」，上方小字固定「聊天」（沒有猜題提示）。不是投放區（v1 不傳圖）。
- 「說明」分頁：主題按鈕 → 說明對話框，內容改寫為繪圖比賽（如何出題、作畫、交卷、評分、排名）。
- 「檔案」選單：「切換偽裝…」（目前只有簡報，仍保留入口）、「說明…」。
- 自動重連：「加入簡報」＋「正在重新加入…」（同 §13.2）。

## 3. 投影片瀏覽（揭曉畫廊，`features/reveal/`）

PowerPoint「投影片瀏覽」檢視：工作區灰底，投影片縮圖以網格排列，**每位參賽者一張**。

```
┌────────────────────────────────────────────────────────┐
│  ① Alice  87 分     ② Bob  74 分     ③ Carol  61 分       │
│  ┌──────────┐      ┌──────────┐      ┌──────────┐       │
│  │  (畫)    │      │  (畫)    │      │  (畫)    │       │
│  └──────────┘      └──────────┘      └──────────┘       │
│  ④ Dave  40 分      ⑤ Eve  未儲存                        │
│  ┌──────────┐      ┌──────────┐                         │
│  │  (畫)    │      │  （空白） │                         │
│  └──────────┘      └──────────┘                         │
└────────────────────────────────────────────────────────┘
```

- 排序＝`results` 的 `rank`。縮圖 16:9、白框 1px `--border`、陰影同投影片；前三名外框 2px `--accent`，名次以投影片編號位置顯示「①②③」（其餘用數字）；自己的那張底 `--bg-active`。
- 前三名外框只給有交卷者。標題列文字：名次、暱稱、分數（`tabular-nums`）；`judgedBy === 'random'` 時分數後加小字「隨機」；未交卷顯示「未儲存」與空白投影片。
- 點縮圖：放大顯示在中央（同「普通檢視」投影片尺寸），再點或 Esc 回網格。Phase 2 可選。
- 寬度：縮圖欄 `repeat(auto-fill, minmax(220px, 1fr))`，間距 16px；< 768px 兩欄。
- 畫廊圖片來自 `contest:gallery` 的 object URL；收不到（極端）顯示灰底「載入中」。

## 4. 響應式與可及性

沿用 DESIGN §8、§9 與 §13.3。工具列收合斷點 **540px**（帆 2026-10-07 實測：完整工具列加「完成」在 518px 開始溢出，留餘裕定 540）；「完成」是獨立插槽 `finish`，固定在功能區右端、不在捲動區內，任何寬度都看得到。已知限制：375px 時右側註解窗格佔約一半寬度、備忘稿列被截斷（繼承自 ppt 版面；手機為範圍外，只記錄不修）。「完成」確認框、投影片瀏覽的縮圖皆可鍵盤操作。
