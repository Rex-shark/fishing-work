# 繪圖比賽（draw-contest）：產品定位與規則

> 平台第二款遊戲。本檔回答「這款遊戲是什麼、怎麼玩、做到哪裡為止」。技術細節與事件契約見 [architecture.md](architecture.md)，畫面對照見 [design.md](design.md)。平台層（首頁 `/`、server、`shared/`）的規範仍以 [../overview.md](../overview.md)、[../architecture.md](../architecture.md) 為準。

---

## 一句話

**所有人同一題、同時畫、交給 AI 評分排名。** 一位玩家出題（例如「蘋果」），其他人與出題者一起在 2 分鐘內各畫各的，畫完交卷，決策模型逐張評「像不像題目」，最後把分數、排名與大家的畫一起揭曉。

## 使用者

與我畫你猜相同：公司區網的同事，2 ～ 30 人同時在線，暱稱即加入、不需帳號、上班偷玩。

## 需求（Rex 2026-10-07）

| # | 需求 | 對設計的影響 |
|---|------|-------------|
| 1 | **先做一個偽裝：簡報（PowerPoint）** | 客戶端 `draw-contest/` 與 `draw-guess/` 完全獨立（Rex 2026-10-07 定案：前端不共用、不抽套件）；起步複製我畫你猜的首頁與 ppt 殼層當底，之後各走各的。殼層註冊表保留，日後可再加偽裝 |

| 3 | **題目出完後大家都進繪圖模式（120 秒）** | 每人一塊自己的畫布，筆跡**只在本機**、不即時中繼；時間到或按「完成」就把畫布 PNG 交給 server |
| 4 | **畫完後圖片給模型打分** | server 收到一張就排進評分佇列（一次一張），不等全部交卷；評分器可抽換：`random`（隨機，**MVP 先用這個，沒有 AI 也能試玩**）與 `ollama`（Clef 決策模型，Phase 3） |
| 5 | **秀出分數與排名，並展示大家的畫**（排版由團隊設計） | 揭曉畫面＝簡報的「投影片瀏覽」：每人一張投影片縮圖＋名次與分數，前三名高亮；揭曉沒有倒數，停到下一回合開始 |
| 6 | **AI 用本地決策模型 Clef，之後以 Ollama 部署**（模型尚在下載） | 評分器走 Ollama 的 `POST /v1/systemone`；模型不在時退回 `random` 並在畫面標示；Docker 部署時容器經 `host.docker.internal` 連主機的 Ollama，模型不進映像 |
| 7 | **AI 評語（Rex 2026-10-12，Epic 15）**：每張畫一句評語，本機 Ollama 的 `gemma4:26b-mlx-bf16`，人格「雌小鬼」、評審名稱**メスガキ**，讓模型自由發揮（規則只有繁體中文台灣用語、一句話 40 字內），只放揭曉卡片，預設開啟 | Clef 仍負責分數，gemma4 只產文字；評語不擋揭曉，晚到再補上；同時 Clef 換 `clef:27b-nvfp4`（MLX）後不再縮圖。規劃 `plan/contest-commentary.md`、契約 architecture §4／§6.1 （2026-10-21 起：規則改 **60 字內**、提示詞帶參賽者暱稱但不加指示、卡片上的評審名改「ミオ」，雌小鬼人格不變；Epic 15 Phase 6／7） |
| 8 | **像不像比賽（Rex 2026-10-26，Epic 20）**：出題者附一張參考圖，大家照著畫，**Clef 比相似度**打分；做成繪圖比賽的一種出題模式（Rex 選），不是第四款遊戲 | 出題對話框加「參考圖（選填）」；有圖的回合 `mode: 'mimic'`：作畫中浮動參考圖面板、Clef 同時看參考圖與作品（不管顏色與線條粗細）、評語也看兩張、揭曉第一格顯示參考圖。詳見 [../../plan/contest-mimic.md](../../plan/contest-mimic.md) |

## v1 遊戲規則

1. **加入**：輸入暱稱（規則與我畫你猜相同：去頭尾空白後 1 ～ 12 字、房內不可重複、不分大小寫、全形英數視同半形）。單一房間。
2. **我出題**：沒有進行中的回合（`idle` 或 `ended`）時，任何人可按「我出題」成為本回合出題者。需至少 2 人在線。
3. **出題**：出題者輸入題目（1 ～ 20 字），可另附一張**參考圖**（選填；Epic 20）：有參考圖的回合是**像不像比賽**，大家照著參考圖畫；參考圖由瀏覽器縮到長邊 1280 以內轉 JPEG 再送。60 秒內未出題、或出題者取消／離線，回到 `idle`。
4. **作畫**：題目送出的瞬間，**當時在線的所有人（含出題者）成為本回合參賽者**，同時進入 2 分鐘作畫（`DRAW_SECONDS`）。每人只看得到自己的畫布；畫具與我畫你猜相同（畫筆、橡皮擦、粗細、顏色、復原、清空、背景色，但背景色只影響自己）。題目全程顯示給所有人。中途加入者本回合旁觀。
5. **交卷**：按「完成」確認後交卷，**交卷後不能再改**；時間到時客戶端自動把目前畫布交卷（含空白）。所有參賽者都交卷即提前結束作畫。
6. **評分**：server 收到一張就排隊評一張（一次一張）。像不像比賽的分數是**與參考圖的相似度**（Clef 同時看參考圖與作品，不管顏色與線條粗細；Epic 20）。評分器給 0 ～ 100 分與信心值。所有參賽者都評完即揭曉；時間到後 5 秒內仍可補交（自動交卷在途），逾時未交者 0 分、標「未交卷」。
7. **揭曉**：依本回合分數高到低排名（同分者先交卷的在前），像不像比賽第一格另顯示參考圖（不排名；Epic 20），顯示每人的畫、分數、名次；評分器為 `random` 或 AI 失敗退回隨機時，畫面標示「隨機評分」。**每張畫另有メスガキ的一句評語**（Epic 15）：揭曉時已產生的直接顯示，還在產生的先顯示「…」、完成再補上；評語失敗或關閉時該張沒有評語行，不影響分數與排名。揭曉沒有倒數，停到有人按「我出題」開始下一回合；中途加入者也看得到上一回合的結果與畫。
8. **總分**：每回合得分累加到玩家總分（伺服器記憶體，重啟歸零）。
9. **聊天**：純文字聊天（200 字、每 300 ms 一則），不傳圖、沒有防洩題（題目本來就公開）。
10. **重連**：與我畫你猜相同的憑證機制（15 秒寬限）。作畫中重新整理會**失去本機未交卷的畫**（筆跡不在 server），重連後畫布為空、仍可繼續畫與交卷。

11. **比賽歷史**（Epic 17，Rex 2026-10-13）：揭曉後把這回合的畫、分數、名次、評語存進**自己的瀏覽器**（IndexedDB），只留最近 5 場、超過刪最舊，不經 server、不同步給別人；從簡報「檔案 › 開啟最近的簡報」回看，作畫中、評分中、自己出題時不能開。規劃 `plan/contest-history.md`、畫面 design §3.1。

## 與我畫你猜的差異（一眼看懂）

| | 我畫你猜 | 繪圖比賽 |
|--|--|--|
| 誰畫 | 一位畫師 | 所有參賽者 |
| 題目 | 只有畫師知道 | 所有人知道 |
| 筆跡 | 即時中繼給所有人 | 只在本機，交卷時送 PNG |
| 判定 | 聊天室答對 | 評分器（random／Clef）打分 |
| 結束 | 全猜對／時間到 | 全交卷且全評完 |
| 揭曉 | 顯示題目 5 秒 | 投影片瀏覽（畫＋分數＋排名），停到下一回合 |
| 前端 | `draw-guess/`，四套偽裝 | `draw-contest/`，先一套 ppt |
