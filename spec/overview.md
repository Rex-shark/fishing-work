# 產品定位與範圍（overview）

> 本檔回答「這個專案是什麼、給誰用、做到哪裡為止」。技術細節見 [architecture.md](architecture.md)。

---

## 一句話

**fishing-work** 是部署在 Rex 本機、同事透過公司區網進來玩的**簡易互動遊戲平台**。第一款遊戲是**我畫你猜（draw-guess）**。

## 使用者

- 同一公司區網內的同事，人數約 2 ～ 30 人同時在線。
- 不需帳號：首頁輸入暱稱即可加入。
- 使用情境是**上班時間偷玩**，因此介面要偽裝成程式編輯器（見「特殊需求」）。

## 特殊需求（Rex 2026-09-24 指定）

| 2 | **要有聊天室** | 聊天室同時是猜題輸入：訊息若命中題目即判定猜對；訊息會廣播給全房間 |

## 我畫你猜 v1 遊戲規則（架構師依常見玩法定案，Rex 可調）

1. **加入**：輸入暱稱（去頭尾空白後 1 ～ 12 字，字數以 Unicode code point 計，房內不可重複；比對時不分大小寫、全形英數視同半形）。所有人進同一個房間（v1 單一房間）。
2. **自願當畫師**：沒有進行中的回合時，任何人可按「我來畫」成為畫師。需至少 2 人在線。
3. **出題**：畫師輸入題目（1 ～ 20 字）。60 秒內未出題則取消，回到等待狀態。
4. **作畫**：回合 2 分鐘（`ROUND_SECONDS`；2026-10-06 前為 90 秒）。畫師有畫筆、橡皮擦、粗細（滑桿左右拖曳，1 ～ 64）、顏色（10 個預設色塊＋顏色面板任選：飽和度／明度方塊與色相條）、復原、清空；工具圖示懸停會顯示功能名稱。其他人只能看。
5. **猜題**：其他人在聊天室輸入文字；與題目**正規化後完全相同**即猜對（去空白、全形轉半形、忽略英文大小寫）。猜對者的訊息不會以原文廣播，而是廣播「X 猜對了」。
6. **防洩題**：畫師與已猜對者若在聊天室輸入含題目的訊息，訊息被擋下並提示本人，不會廣播。
7. **提示**：猜題者看得到題目字數（例如「＿ ＿ ＿」）。
8. **回合結束**：所有非畫師都猜對、或 2 分鐘到、或畫師離線／放棄。結束時向所有人揭曉題目，停 5 秒後回到等待狀態。畫布保留到下一回合開始才清空。
9. **計分**（保留在伺服器記憶體，伺服器重啟歸零）：
   - 猜對者：`100 − floor(50 × 已用秒數 / ROUND_SECONDS)`（目前 120 秒），即 50 ～ 100 分，越快越高。
   - 畫師：每有一人猜對 +20 分。
10. **離線**：斷線後有 **15 秒寬限期**，期間分數與畫師身分保留，回來（含重新整理頁面）即接續；畫師在寬限期內回合不中止、計時照走。寬限逾期才視為離開：畫師離開則回合結束（原因：畫師離開），猜題者離開則從「全員猜對」的計算中移除。

## 範圍內（v1）

- 單一房間、暱稱加入、玩家清單與分數。
- 聊天室圖片：拖曳上傳、即時中繼、不保留（Epic 2）。
- 多偽裝主題：vscode 與 ppt 兩套殼層（Epic 3）、meet 視訊會議殼層（Epic 5）、excel 試算表殼層（Epic 13）；柔和 UI 首頁以卡片選風格（Epic 4）。
- 回合狀態機、畫布即時同步、中途加入者可看到目前畫面。
- 聊天室、猜題判定、防洩題、計分、揭曉。
- IDE 風格深色介面。
- 區網部署：單一 Node 程序綁 **80 埠**（公司區網只放行標準埠），同事以 `http://<Rex 的區網 IP>/draw-guess/` 進入。

## 範圍外（v1 不做，日後再議）

- 帳號、登入、權限。
- 語音輸入（麥克風）：2026-09-29 暫緩，區網 http 下瀏覽器不開放麥克風，見 `plan/voice-input.md`。
- 多房間、私人房、密碼。
- 內建題庫、隨機出題、多語言題目。
- 歷史戰績、排行榜持久化（無資料庫）。
- 圖片保存、相簿、上傳進度、燈箱（圖片只即時中繼）。
- 手機觸控最佳化（能用即可，不特別調校）。
- Docker、自建 HTTPS（外網存取改由 Cloudflare Tunnel 提供，見 architecture §3）。
- 第二款以後的遊戲（平台結構預留，見 architecture.md）。

## 非功能需求

| 項目 | 要求 |
|------|------|
| 延遲 | 區網內筆跡同步肉眼無感（< 100 ms） |
| 人數 | 30 人同時在線不掉訊息 |
| 啟動 | 一個指令啟動，不依賴資料庫或外部服務 |
| 區網可達 | 伺服器綁所有介面、**80 埠**（5173 等非標準埠被公司網路擋掉），啟動時印出區網網址；同事用 `http://<Rex IP>/draw-guess/` 直接開，客戶端不需設定任何位址（Rex 2026-09-24 明確要求） |
| 外網可達（備用） | 同一程序經 Cloudflare Tunnel 的 HTTPS 網址也能玩（Rex 2026-09-24 補充；隨後更正區網實測可連，tunnel 為備用）；無登入，靠網址不外流，人數上限 50 |
| 復原 | 重新整理頁面或短暫斷線，15 秒內自動接回，分數與畫師身分不丟 |
| 語言 | 介面文字繁體中文（台灣用語）；偽裝用的 IDE 元素（分頁名、狀態列）可用英文以求逼真 |
